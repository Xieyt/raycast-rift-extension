# Changelog

## [Initial Release] - {PR_MERGE_DATE}

- Window switching within the focused workspace
- Window switching across all workspaces, grouped by workspace
- Workspace navigator with window count display
- Fuzzy search by app name and window title
- App icons via macOS Spotlight
- Window focusing via AppleScript (PID + AXRaise)
- Workspace switching via `rift-cli execute workspace switch <index>`
- `Show Window Titles First` preference per command
- Shell PATH resolution via `shell-env` for Nix/non-standard installs
